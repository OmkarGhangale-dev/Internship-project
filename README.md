# Internship Project

A responsive frontend web application developed during my internship to demonstrate modern web development skills using HTML, CSS, and JavaScript.

## 📌 Overview

This project was built as part of my internship training to strengthen my understanding of frontend web development. It focuses on creating a clean, responsive, and interactive user interface while following standard web development practices.

## 🚀 Features

- Responsive design for different screen sizes
- Modern and clean user interface
- Interactive functionality using JavaScript
- Organized and maintainable code structure
- Fast and lightweight implementation

## 🛠️ Technologies Used

- CSS3
- JavaScript (ES6)
